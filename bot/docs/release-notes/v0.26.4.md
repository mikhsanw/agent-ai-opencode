## Changes
- **Prebuilt Docker images** — stable releases are now published as multi-arch (`linux/amd64`, `linux/arm64`) images on `ghcr.io/grinev/opencode-telegram-bot`, so you can pull the bot instead of building it locally. ([@mitchellhuang](https://github.com/mitchellhuang))
- **Docker health check** — the Docker image now reports the container as `unhealthy` when the bot stops responding, through a loopback-only health endpoint that also tells whether OpenCode is reachable.

## Fixes
- **Background subagents on OpenCode V1** — a subagent launched in the background keeps its live card after the turn ends instead of losing it with the parent's reply. ([@vheins](https://github.com/vheins))
- **Tool lines** — a tool call no longer appears as a bare tool name while the agent is still composing it; its line shows up once, already complete with its arguments.
- **Starting subagent cards** — a new subagent card shows a short `🧩 Starting task` line until its task, agent and model are known, instead of `Unknown` or empty labels, and parallel subagents no longer swap each other's task and agent.
- **Interrupted subagents** — a subagent stopped by `/abort`, an attached OpenCode TUI or Desktop, or the server now ends its card with `⏹ Interrupted` instead of `✅ Completed` or `❌ Aborted`.
- **Nested subagents** — a subagent launched by another subagent now shows as a `🤖 Running Task` line on its parent's card instead of getting a card of its own.
- **Pinned dashboard after a switch or restart** — the pinned status message shows the session's real context, cost and changed files from the moment it appears, instead of zeros until the next update.
- **Pinned dashboard after a model change** — picking a model, or an agent that brings its own model, updates the pinned status message to that model and its context limit right away, even mid-run.
